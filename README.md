# 🍲 safwansatil

I'm a Software Engineering undergraduate (2nd Year, IUT) focused on mastering the MERN Stack while aggressively expanding my skills into Next.js and TypeScript. I'm driven by the goal of becoming a high-impact SWE engineer, particularly excited by the potential of ML/AI applications.

My approach to development is all about planning and collaboration. I build my projects from the backend up, concentrating on creating clean architecture and efficient database designs. This ensures the foundational work is solid, making the rest of the development process smooth and enjoyable for anyone involved. I love diving into complex, real-world puzzles, whether that means mastering DSA and C++ fundamentals for university or building functional tools like live chat systems.
